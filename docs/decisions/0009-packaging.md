# 0009 — Packaging: export presets, build script, app art, Steam depots, CI

- Context: the game could not be shipped: no export presets, no icon, no build command, no depot files, no CI. It reads `data/*.json` and the font licences as plain files (`DataReader`, `LicenceTexts`); the licences are no resources, so an export drops them unless a filter names them.
- Decision: `export_presets.cfg` holds three presets: `Windows` (x86_64), `Linux` (x86_64, also the Steam Deck's build) and `macOS` (universal). Each exports all resources — models are loaded through paths built from strings, so "selected resources" is out — plus `data/*.json` and `assets/ui/font_*_license.txt` by the include filter, and leaves out tests, `addons/gut/`, `scripts/`, `docs/`, `art-src/`, the `*_preview` scenes, `steam/`, `.github/` and `.gutconfig.json`. The pack stays a file beside the executable. The file lists only the options that matter; the editor adds the rest with their defaults when it saves the presets.
- Decision: `node scripts/build.mjs [windows|linux|macos|all]` is how builds are made: import, release export into `build/<platform>/` as `thronstreit.exe`, `thronstreit.x86_64` or `thronstreit.zip` (Godot writes a bare `.app` only on a Mac), `version.txt` from `config/version`. It fails on a non-zero exit code, on an `ERROR` line of the export (Godot reports many failures only that way) and when the pack lacks a plain file or holds a test or tool; `scripts/pck_files.mjs` reads a pack's directory, also inside the macOS zip.
- Decision: one master for the app art, `art-src/ui/icon_app.svg` (a heater shield with a crown, gold on dark). `scripts/make_app_art.gd` renders `assets/ui/icon_app.png` (512 px, `config/icon`) and the boot splash `assets/ui/splash_boot.png` (the crest and the name in Texturina, 1280×720 on the boot colour, which is the curtain's colour). Godot 4.7 writes the icon (16–256 px) and the version into the Windows executable itself and builds the macOS `.icns`, so there is no `.ico`, no `.icns` and no rcedit.
- Decision: `rendering/textures/vram_compression/import_etc2_astc` is on, because a universal (or arm64) macOS export refuses to run without it.
- Decision: the macOS bundle is signed ad hoc by Godot's built-in signer and not notarised; its bundle identifier `com.dreamstudios.thronstreit1198` is provisional. Signing and notarisation wait for the owner's Apple developer account (0003).
- Decision: `steam/` holds the SteamPipe scripts as templates with `REPLACE_WITH_…` placeholders for the app id and the depot ids, and a README with the upload steps, launch options, Auto-Cloud, Steam Deck and Remote Play Together. Saves and options sync through Auto-Cloud on the fixed user folder (0010), so the builds carry no Steamworks SDK; GodotSteam stays a later step (0003).
- Decision: `.github/workflows/ci.yml` runs import, gdlint, the typecheck and the GUT suite on every push and pull request with Godot 4.7.2 and gdtoolkit 4.5.0; a `v*` tag also exports the three platforms, starts the Linux build headless and keeps the builds as artifacts.
- Consequences: a new kind of plain file read from `res://` needs the include filter of all three presets and `plainFiles()` in `build.mjs`; a new folder of tools needs the exclude filter. `src/render/app/test_packaging.gd` guards the filters and the app art.
- Consequences: with ETC2/ASTC on, every VRAM-compressed texture is imported in two formats; the project has none today (UI textures are lossless, models carry no textures).
- Consequences: a Windows release build has no console; its output is in `user://logs/godot.log`.
- Consequences: the editor loads the GUT plugin during an export, and its update check fails without a network; `build.mjs` ignores exactly those two error lines.
